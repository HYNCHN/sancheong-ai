# 산청아이(AI)

산청군 초등학생을 위한 학교·날씨·공부 정보 웹앱입니다. (교육용·비영리)

- 학생 개인정보를 받지 않습니다. 학교·학년·반·읍면 선택은 학생 휴대폰 안에만 저장됩니다.
- 정보 출처: 나이스 교육정보 개방포털, 기상청 단기예보, 에어코리아, 관리 시트(구글 스프레드시트)

## 폴더 구성

| 위치 | 내용 | 고칠 일 |
|---|---|---|
| `public/` | 학생이 보는 화면 (HTML, CSS, JS, 아이콘) | 거의 없음 |
| `public/art.js` | 지리산 장면, 날씨 그림, 아이콘 (시간·계절에 따라 바뀜) | 거의 없음 |
| `public/img/friend.png` | 안내 캐릭터 그림 (없으면 옷 그림이 대신 나옴) | 캐릭터 승인 후 넣기 |
| `src/index.js` | 중계 서버 (나이스·기상청·에어코리아·시트를 대신 불러옴) | 거의 없음 |
| `apps-script/시트_읽기_웹앱.gs` | 관리 시트를 읽어 주는 Apps Script | 처음 한 번 설치 |
| `wrangler.jsonc` | Cloudflare 설정 | 고치지 않음 |

## 비밀 값 (Cloudflare → Worker → 설정 → 변수 및 비밀)

모두 **비밀(Secret)** 유형으로 넣습니다. 코드에는 절대 넣지 마세요.

| 이름 | 값 |
|---|---|
| `NEIS_KEY` | 나이스 교육정보 개방포털 인증키 |
| `DATA_KEY` | 공공데이터포털 일반 인증키 (Decoding) |
| `SHEET_URL` | 시트 읽기 Apps Script 웹 앱 주소 (`https://script.google.com/macros/s/.../exec`) |

설정 확인: 앱 주소 뒤에 `/api/health` 를 붙여 열면 세 값이 모두 `true` 인지 보입니다.

## 관리 시트로 바꿀 수 있는 것

- **설정** 탭: 공지 배너, 메뉴 켜기·끄기, 문의 연락처, `의견_주소`(의견 설문지 주소), `미세먼지_측정소`(기본 산청읍)
- **공부_*, 우리고장, 계기교육, 절기** 탭: 오늘의 공부와 홈 화면 안내
- **옷차림, 날씨_추가안내** 탭: 날씨 카드 문구
- **학교추가정보** 탭: 학교 소개·자랑거리

시트를 고치면 30분 안에 앱에 반영됩니다.

## 코드 고치기

GitHub에서 파일을 고치거나 새로 올리면 Cloudflare가 자동으로 다시 배포합니다(1~2분).

## 참고

- 날씨 격자는 읍·면사무소 부근 좌표로 계산했습니다 (`src/index.js`의 `TOWNS`).
- 나이스 데이터가 없는 날은 "시간표가 아직 없어요", "급식이 없는 날이에요"로 표시됩니다.
